# Kids School Landing Page 🎒🏫

🔗 **Live Demo:** https://kids-education-two.vercel.app/

This is a **practice frontend project** built using **HTML and CSS**.  
The project represents a **Kids School / Education landing page** designed to showcase a modern school website layout with curriculum sections, storytelling content, and a responsive user interface.

The main objective of this project was to practice **responsive layouts, navigation menus, CSS Flexbox & Grid**, and real-world UI components commonly used in educational and institutional websites.

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- Google Fonts (Quicksand)  
- CSS Flexbox  
- CSS Grid  
- Media Queries (Mobile & Tablet Responsive Design)

---

## ✨ Features

- Responsive navigation bar with **CSS-only mobile toggle menu**
- Hero section with call-to-action (**Enroll Now**)
- Curriculum section with **custom card designs**
- Multi-color themed curriculum cards
- Stories / Blog section using **CSS Grid**
- Highlighted featured story layout
- Call-to-action buttons (UI only)
- Clean footer with navigation & social icons
- Smooth layout transitions and spacing
- Fully responsive across devices

---

## 📱 Responsiveness

### Desktop
- Multi-column layouts  
- Grid-based story cards  
- Full navigation menu  

### Tablet
- Optimized content width  
- Two-column story layout  
- Touch-friendly spacing  

### Mobile
- Single-column layout  
- Hamburger menu (**CSS checkbox toggle**)  
- Scaled images & typography  

Images scale responsively while maintaining aspect ratio.

This project was created **purely for practice purposes** to:

- Improve HTML semantic structure  
- Practice responsive navigation without JavaScript

- Strengthen responsive design skills
